Workspaces & monitors

Super 1–9 Go to workspace
Super ⇧ 1–9 Move window there, follow
Super ⇧ Alt 1–9 Move window there, stay
Super Tab Last workspace Mac
Alt ` Last workspace (Alt Tab stays native) Win
Super Ctrl Tab Next workspace (⇧ previous)
Win Alt Ctrl → / ← Next / previous workspace
Super ⇧ Alt ←→ Workspace → monitor
Super ⇧ Ctrl ←→ Window → monitor
Directional focus crosses monitors. Service mode (Super ⇧ ;): hjkl window → monitor, ⇧ hjkl workspace → monitor.
